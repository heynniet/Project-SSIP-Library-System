# SSIP Library System

A web-based Library Management System developed using PHP and MySQL as part of an
academic course project.

This system aims to facilitate book borrowing, donation management, and
administrative functions to streamline library operations for both users and
administrators.

## 📌 Overview
The application provides an intuitive interface for book discovery, borrowing
processes, and overall library resource management.

## 🚀 Features
- Book management
- Member management
- Book borrowing and returning
- Donation management
- Admin dashboard
- CRUD operations
- Database-driven system

## 🛠️ Tech Stack
- PHP
- MySQL
- HTML
- CSS
- JavaScript
- XAMPP

## ⚙️ How to Run
1. Install **XAMPP**
2. Move the project folder into:
   ```text
   htdocs/
3. Start Apache and MySQL from XAMPP Control Panel
4. Import the database file from the DATABASE folder using phpMyAdmin
5. Open the application in your browser:
   http://localhost/your-project-folder
## 🗄️ Database
  MySQL database
  SQL file available in the DATABASE directory
